The .otl file ✕

Everything — the whole tree and every page — lives in one UTF-8 JSON file. New / Open / Save move that single file, exactly like the source .mpl kept its whole database in one blob, just human-readable now.

Fields, mapped from the original MainTable:

idNode_AUTOINC — stable node key
titleNode_ITEM — the outline label
childrenNode_MASTER + Node_DETAIL, folded into nesting
bodyNode_DATA — page text (RTF → HTML subset)
iconNode_IMAGE — note · folder · doc · task
markedNode_MARKED — the teal flag
expandedUI state, saved with the tree
{
  "format": "otl-outline",
  "version": 1,
  "meta": { "title": "My notes" },
  "tree": [
    {
      "id": "n_code",
      "title": "code notes",
      "icon": "folder",
      "marked": false,
      "expanded": true,
      "body": "<p>…</p>",
      "children": [ … ]
    }
  ]
}

Dropped from the binary original: the Absolute Database container, the separate Version / Header / Icons tables, and the relational master–detail join. The tree carries its own shape.
